---

# AI Tools Required:

* ChatGPT / DALL·E
* Google Gemini
* Midjourney
* Stable Diffusion

---

# Introduction:

Text-to-image generation is an Artificial Intelligence technique that creates images from natural-language prompts. The generated output depends on the details provided in the prompt, such as the subject, colors, composition, lighting, perspective, texture, environment, and artistic style.

In this experiment, two reference images are selected for reproduction. Each image is carefully analyzed to identify its major visual characteristics. A basic prompt is created first, followed by refined and detailed prompts. The final prompt is then used with an image-generation tool to create a similar image. The original and generated images are finally compared to identify similarities and differences.

---

# Procedure:

### 1. Analyze the Given Image

Examine each reference image carefully and identify:

* Objects and subjects
* Dominant colors
* Textures
* Lighting conditions
* Background and foreground
* Composition
* Perspective
* Artistic style
* Mood and atmosphere

### 2. Create the Basic Prompt

Write a simple description containing the main subject and environment of the image.

### 3. Refine the Prompt

Add more information about:

* Object positions
* Colors
* Lighting
* Background
* Perspective
* Composition
* Mood

### 4. Identify the Style

Determine whether the image is realistic photography, digital artwork, vector illustration, painting, cartoon, cinematic artwork, or another style.

### 5. Create the Final Detailed Prompt

Combine all important visual characteristics into a single detailed prompt.

### 6. Generate the Image

Enter the final prompt into a text-to-image generation tool such as DALL·E, Gemini, Midjourney, or Stable Diffusion.

### 7. Compare the Images

Compare the original and generated images based on:

* Subject
* Composition
* Colors
* Lighting
* Perspective
* Background
* Style
* Overall similarity

### 8. Refine if Required

If important elements are missing or incorrect, modify the prompt and generate another version.

# PROMPT REFINEMENT ANALYSIS

The experiment was performed using three levels of prompt complexity.

### Level 1 – Basic Prompt

The basic prompt described only the main subject.

**Example:**

> "A countryside dirt road next to a river with mountains during sunset."

This generated a general representation of the desired scene.

### Level 2 – Refined Prompt

The second prompt included spatial relationships, colors, and important environmental features.

**Example:**

> "A dirt road leading through green grass on the right, a calm river on the left, and a bright sun setting behind blue mountains under a dramatic orange and purple sky."

The generated output became more closely aligned with the reference image.

### Level 3 – Detailed Prompt

The final prompt included:

* Subject placement
* Foreground and background
* Color palette
* Lighting
* Perspective
* Texture
* Composition
* Atmosphere
* Artistic style
* Mood

This resulted in the closest reproduction of the reference image.

---

# OBSERVATIONS:

1. Basic prompts are sufficient for generating the general concept of an image.
2. Adding spatial information improves the composition of the generated image.
3. Describing specific colors helps reproduce the visual appearance of the reference.
4. Lighting instructions strongly influence the mood and realism of the output.
5. Specifying perspective helps control the viewpoint of the generated scene.
6. Describing textures improves the visual details of objects and environments.
7. Identifying the artistic style helps the AI model produce an appropriate visual treatment.
8. Iterative prompt refinement produces better results than using a single generic prompt.
9. Even detailed prompts may not reproduce every object in exactly the same position.
10. The final output depends on the capabilities and interpretation of the selected image-generation model.

---

# ADVANTAGES:

* Images can be generated quickly from natural-language descriptions.
* No advanced drawing skills are required.
* Prompts can be easily modified to change visual elements.
* Different artistic styles can be explored.
* Multiple versions can be generated for comparison.
* Useful for creative design, presentations, advertisements, and concept development.

# LIMITATIONS:

* Exact reproduction of an existing image is difficult using text alone.
* Small objects and background details may change.
* Object positions may not exactly match the reference.
* Generated text or symbols inside images may contain inaccuracies.
* Different AI models may interpret the same prompt differently.
* Several prompt iterations may be required to achieve a close match.
